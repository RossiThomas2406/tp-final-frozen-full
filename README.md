# Food Production & Logistics Management System 

This is a Full-Stack software solution designed to migrate a frozen food SME's production workflow from legacy, manual Excel sheets to an automated, scalable web application. Developed by an Agile team using SCRUM and JIRA.

## Tech Stack

* **Backend:** Python (Scalable API Services)
* **Database:** PostgreSQL (Relational Data Modeling & Query Optimization)
* **Frontend:** React.js, JavaScript, HTML5, CSS3
* **Deployment:** Vercel

---

## Key Features

* **Role-Based Access Control (RBAC):** Implemented a robust security system on the backend to secure endpoints, dynamically rendering the React.js user interface based on the employee's corporate role.
* **KPI Analytics Dashboard:** A dynamic data-driven module providing real-time production analytics and key business performance indicators for stakeholders.
* **Facial Recognition Authentication:** Integrated secure user authentication via facial recognition logs.
* **Production Line Tracking:** Complete relational database schema to manage raw material orders, custom recipes, and active production lines.

---

## Project Context

This system was developed as part of a final software project at **Universidad Nacional de General Sarmiento (UNGS)**. Deliverables and milestones were presented and validated under strict client-vendor simulations with university professors acting as corporate stakeholders.
